# Day 04 — 습관 체크

매일 지킨 습관을 탭 한 번으로 체크하는 개인용 습관 트래커.

- 이름 등록 후 습관을 최대 10개까지 등록 (이름·소요시간·빈도(매일/주 N회/월 N회)·기간)
- 습관 이름으로 카테고리(공부/운동/콘텐츠/마음돌봄/자기관리)를 자동 분류
- 오늘 화면에서 탭 한 번으로 체크, 습관별 연속 기록(스트릭) 표시
- 너그러운 규칙: 매일 습관은 일주일에 하루 빼먹어도 스트릭이 끊기지 않음 (주/월 단위 습관도 1회 면제)
- 한 주/한 달을 모든 습관 기준으로 다 채우면 뱃지 획득
- 통계 화면: 날짜별 달성률을 색 농도로 표시하는 달력, 습관별 이번 달 달성률·최장 스트릭·누적 시간
- 오늘의 체크 현황을 9:16 이미지로 저장 가능

데이터는 모두 `localStorage`에 저장, 빌드 없이 `index.html` 하나로 동작합니다.

Open `index.html` directly in a browser to run it.
