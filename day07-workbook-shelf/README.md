# Day 07 · 문제집 책장

푼 문제집을 표지로 모아 책장처럼 진열하는 앱. 타깃은 중고등학생.

## 쓰는 법

1. 닉네임과 학년(중1~고3)을 등록하면 "○○의 문제집 책장"이 만들어진다.
2. **＋ 문제집 추가** → 표지 사진을 찍거나 앨범에서 고르고, 제목 검색이나 뒷면 바코드(ISBN) 스캔으로 제목·출판사를 가져온다. 검색이 안 되면 그대로 직접 입력으로 넘어간다.
3. 제목을 분석해 **과목**(수학/영어/국어/과학/사회/한국사/기타)과 **대상 학년**을 자동 분류한다. 둘 다 저장 전에 고칠 수 있다.
4. 추가하면 "시작한 날"이 기록된다(날짜 수정 가능).
5. 진행 중인 문제집의 **다 풀었어요!** 버튼을 누르면 완료일이 기록되고 축하 효과가 뜬다. 시작일~완료일로 걸린 날수가 자동 계산된다.
6. 다 푼 문제집은 아래 책장에 표지가 보이게 진열된다(최근 완료가 앞).
7. 📊 통계에서 과목별 권수·올해 총 권수·평균 소요 일수를, 📤에서 책장을 9:16 이미지로 저장한다.

## 실행

`index.html`을 브라우저에서 그대로 열면 된다. 빌드 없음, 의존성 없음, 데이터는 `localStorage`(키: `workbook-shelf-v1`)에 저장된다.

## 책 검색에 대해

- 기본은 **Google Books API**(day01 독서 달력과 같은 키)를 쓴다. 이 키는 `bominkimkr.github.io` 리퍼러로 제한돼 있어서 **GitHub Pages에 올라간 주소에서만 검색이 된다.** 로컬 파일로 열면 검색이 실패하는데, 이때는 안내와 함께 직접 입력으로 자연스럽게 넘어간다.
- 한국 문제집은 구글 검색 결과가 부실할 때가 많다. ⚙️ 설정에 **카카오 책 검색 REST 키**를 넣으면 그쪽을 우선 사용한다(리퍼러 제한이 없어 로컬에서도 검색됨).

## 바코드 스캔

브라우저 내장 `BarcodeDetector`(Chrome/Android 계열)를 쓴다. 지원하지 않는 브라우저나 카메라 권한이 없으면 같은 화면에서 ISBN 숫자를 직접 입력할 수 있다.

## 표지

- 사진을 올리면 2:3으로 잘라 480×720 JPEG로 저장한다.
- 사진을 올리지 않으면 검색 결과의 표지를 가져오고, 그것도 없으면 과목 색으로 표지를 만들어 준다. 그래서 책장은 항상 표지가 채워진 상태로 보인다.
