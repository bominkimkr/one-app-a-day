# Day 09 — 대치동 설명회 모아보기

대치동 학원 9곳의 **설명회 공지를 매일 아침 6시(KST)에 자동으로 모아** 한 화면에 보여주는 정보 앱입니다.
폰에서 열어 오늘·이번 주 설명회를 훑고, 관심 있는 건은 원문으로 바로 넘어가는 용도입니다.

## 실행

```
start day09-seminar-board/index.html      # 브라우저에서 바로 열기 (빌드 없음)
```

`index.html` 은 먼저 `data.json` 을 `fetch` 하고, `file://` 로 열어 막히면 같은 내용이 담긴
`data.js` 로 넘어갑니다. 그래서 로컬에서 그냥 더블클릭해도 동작합니다.

수집을 직접 돌리려면:

```
cd day09-seminar-board/scrape
pip install -r requirements.txt
python collect.py                  # data.json + data.js 갱신
python collect.py --dry-run        # 저장하지 않고 결과만 출력
python collect.py --only mexx,snt  # 특정 학원만 다시 수집
```

**저작권 때문에 자료 전문은 가져오지 않습니다.** 저장하는 건 제목 · 게시일 · 설명회 일시 ·
장소 · 원문 링크뿐이고, 본문 텍스트와 첨부·이미지는 담지 않습니다.
지난 설명회는 180일치까지만 남기고 그보다 오래된 건 버립니다.

### 학원별로 알아둘 점

- **시대인재**: 게시판 구조는 정상이지만 대치캠퍼스에 *진행 중인 설명회가 없으면* 목록이 비어
  나옵니다. 그래서 평소에도 `empty` 로 뜰 수 있습니다(수집 실패가 아님).
- **KNS**: 전용 설명회 게시판(`high/sub3/50_2.php`)이 2023년 이후로 갱신되지 않아 쓰지 않습니다.
  대신 실제로 살아 있는 초등부·중등부·고등부 공지사항에서 설명회성 글만 골라 옵니다.
  세 서브도메인 모두 https 를 지원하지 않아 http 로 접근합니다.
- **대찬학원 / 세정학원 / 다원교육 / SNT / 새움학원**: 게시판에 *등록일 컬럼이 없습니다.* 이 경우 앱이 글을
  처음 발견한 날(`first_seen`)을 등록일 대신 쓰고, 카드에 `· 수집일` 이라고 표시합니다.
- **세정학원 / 새움학원**: 글마다 개별 URL이 없어 원문 링크가 해당 목록 페이지로 갑니다.
- **새움학원**: 날짜가 별도 컬럼이 아니라 제목 안에 "`26.8.7)" 식으로 박혀 있어, 제목에서 날짜를
  직접 뽑아냅니다. 한 제목에 여러 날짜가 있으면 오늘 이후 중 가장 가까운 날짜를 씁니다.

## 대상 자동 분류

제목 + 게시판 힌트에서 학년 표현을 뽑아 **초등 / 중등 / 고등** 으로 나눕니다.
아무 학년 신호도 없으면 `levels` 가 비고 화면에는 **전체**로 표시되며, 어느 탭에서도 보입니다.

- `초5~6`, `중1-3` 같은 범위 표현을 펼칩니다.
- `예비고1` 은 **현재 학년 기준**으로 봅니다 → 예비고1 = 현 중3 = **중등**.
  (예비고2 → 고1, 예비중1 → 초6 도 같은 규칙)
- `2009년생` 같은 출생연도 표기는 한국 학제로 환산합니다 (2026년 기준 2009년생 → 고2).
- `수능 / 수시 / 9평 / 의대 입시` 처럼 학년은 없지만 고등 대상이 분명한 표현도 고등으로 봅니다.

분류 규칙은 전부 `scrape/classify.py` 한 곳에 모여 있습니다.

## 자동 업데이트

`.github/workflows/seminar-board.yml` 이 매일 **21:00 UTC (= 06:00 KST)** 에 `collect.py` 를
돌리고, 바뀐 `data.json` / `data.js` 를 커밋·push 합니다. GitHub Pages라 push 만으로 반영됩니다.

- 한 학원이 실패해도 나머지는 그대로 수집합니다. 실패한 학원은 **직전에 성공한 데이터를 그대로 유지**하고,
  `data.json` 의 `academies[].status = "fail"`, `last_success_at` 으로 언제가 마지막 성공이었는지 남깁니다.
- 앱 상단 "수집 현황"을 펼치면 학원별 상태·건수·마지막 성공 시각을 볼 수 있습니다.
- 워크플로 실행 요약(Actions Summary)에도 학원별 성공/실패 표가 남습니다.

## 화면

- 상단 탭 **전체 / 초등 / 중등 / 고등**, 그 아래 학원별 필터 칩
- 정렬 토글: **최신순**(등록일) ↔ **설명회 임박순**
- **📌 이번 주 설명회** — 오늘부터 7일 안의 일정만 따로 위에 모음 (D-day 표시)
- 카드: 학원 색 라벨 · 대상/학년 태그 · 제목 · 설명회 일시 · 장소 · 등록일 · `원문 보기`
- **NEW** 뱃지: 오늘/어제 올라온 글.
  단, 어떤 학원을 *처음* 수집한 회차에 딸려 들어온 기존 글에는 붙이지 않습니다
  (안 그러면 첫 실행에서 전부 NEW가 되어 버립니다).
