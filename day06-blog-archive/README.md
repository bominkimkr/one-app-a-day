# Day 06 — 내 블로그 아카이브

본인 소유의 네이버 블로그 글을 개인적으로 백업/아카이브하는 앱.

브라우저 보안 정책(CORS) 때문에 정적 페이지가 네이버 블로그를 자동으로 통째로 긁어올 수는 없어서, 아래 방식으로 동작합니다.

- 북마클릿("📥 블로그 글 가져오기")을 북마크바에 등록해두면, 본인 블로그 글 페이지에서 클릭했을 때 제목+본문을 클립보드에 복사해줌
- 앱에서 "📋 클립보드 붙여넣기"로 바로 등록하거나, 직접 붙여넣기/입력도 가능
- 제목/날짜/태그로 글을 정리하고 검색 가능
- 전체 아카이브를 JSON(다시 불러오기 가능한 백업)과 읽기 좋은 HTML 파일로 내보내기

데이터는 모두 `localStorage`에 저장, 빌드 없이 `index.html` 하나로 동작합니다.

Open `index.html` directly in a browser to run it.
