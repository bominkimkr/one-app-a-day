내 블로그 글 가져오기

브라우저 보안 정책 때문에 이 앱이 네이버 블로그를 자동으로 통째로 긁어올 수는 없어요. 대신 아래 버튼(북마클릿)을 쓰면 글 하나하나를 빠르게 복사해올 수 있어요.

👇 이 버튼을 북마크바로 드래그하세요
📥 블로그 글 가져오기
  1. 위 버튼을 브라우저 북마크바(즐겨찾기 바)로 드래그해서 저장
  2. 내 블로그의 글 페이지로 이동
  3. 북마크바의 "📥 블로그 글 가져오기" 클릭 → 제목+본문이 복사됨
  4. 이 앱으로 돌아와 "📋 클립보드 붙여넣기" 클릭

블로그 디자인에 따라 자동 추출이 안 될 수도 있어요. 그럴 땐 글을 직접 드래그해서 복사한 뒤 "새 글 추가"에 붙여넣어주세요.
