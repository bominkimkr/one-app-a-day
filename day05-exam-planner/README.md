# Day 05 — 시험 계획표

시험 날짜에서 거꾸로 계산하는 중고등학생용 역순 계획표.

- 시험 이름, 과목(자동 색상), 과목별 시험 범위(텍스트 또는 사진 여러 장)와 시험 날짜들을 등록
- 시험 첫날 기준 4주 전~1주 전~시험주간을 자동으로 생성 (남은 기간이 짧으면 남은 주차만 생성), 주차마다 응원 명언 표시
- 전체 계획표에서 날짜·과목별로 할 일을 입력하고 체크, 시험 날짜는 눈에 띄게 강조
- 오늘 화면: D-day 카운트다운, 오늘 할 일 체크, 밀린 할 일은 "밀림" 표시와 함께 다른 날로 옮기기 가능
- 오늘 화면에서 과목 칩을 눌러 시험 범위(텍스트/사진)를 바로 확인
- 오늘의 진행 상황을 9:16 이미지로 저장 가능
- 시험이 끝나면 메뉴에서 "시험 완료 처리" 후 새 시험 등록 가능

데이터는 모두 `localStorage`에 저장, 빌드 없이 `index.html` 하나로 동작합니다.

Open `index.html` directly in a browser to run it.
