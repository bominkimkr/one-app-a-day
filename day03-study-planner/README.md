# Day 03 — 스터디 플래너

종이 스터디 플래너를 그대로 옮긴 개인용 하루 계획 앱. 중고등학생 대상.

- 처음 열면 이름을 등록하고 바로 "○○의 스터디 플래너"로 들어감 (설정에서 이름/시간대 변경 가능)
- 왼쪽엔 오늘의 계획(과목·세부내용·목표시간, 과목마다 자동 색상), 오른쪽엔 10분 단위 타임테이블
- 계획을 선택하고 타임테이블을 클릭/드래그하면 형광펜처럼 칠해지고, 계획별 목표 대비 실제 시간이 자동 집계됨
- "어제 계획 불러오기"로 반복되는 과목을 빠르게 다시 등록
- "오늘 마무리"로 달성률·총 공부시간 확인, 100% 달성 시 배지 + 연속 스트릭 표시
- 한 달 보기: 날짜별 달성률을 색 농도로 표시, 총 공부시간/과목별 비중/최장 스트릭 통계
- 오늘의 기록을 9:16 이미지로 저장 가능 (하단에 앱 이름·주소 표시)

데이터는 모두 `localStorage`에 저장, 빌드 없이 `index.html` 하나로 동작합니다.

Open `index.html` directly in a browser to run it.
