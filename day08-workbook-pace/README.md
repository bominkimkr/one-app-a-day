# Day 08 · 문제집 하루 분량

어떤 문제집이든 등록하면 하루에 풀 분량을 계산해 주고, 매일 완수하도록 챙겨 주는 앱.

## 쓰는 법

1. 닉네임과 학년을 등록한다.
2. **＋ 문제집 등록** → 표지 사진을 올리고, 제목을 검색해 제목·출판사·총 페이지수를 자동으로 채운다. 여러 권을 동시에 등록할 수 있다.
3. 하루 분량은 두 가지 방식 중 고른다. 입력하는 즉시 아래 미리보기에서 결과를 보여 준다.
   - **하루에 몇 쪽?** → `하루 20쪽씩 풀면 25일 걸려요. 9월 30일에 완주 예정!`
   - **언제까지?** → `500쪽 ÷ 25일 = 하루 20쪽!`
4. 홈에 오늘 풀 범위가 크게 뜬다: `p.41 ~ p.60` / `오늘 20쪽`.
5. 다 풀면 **✅ 오늘 분량 완수!**, 조금만 했으면 **조금만 했어요**에서 지금까지 푼 마지막 쪽을 넣는다. 남은 분량과 완주 예정일이 바로 다시 계산된다.
6. 밀린 날이 있으면 `⏰ 어제까지 분량이 120쪽 밀렸어요. 이 페이스면 완주가 10일 늦어져요. (9월 15일 → 9월 25일)`처럼 알려 준다.
7. 연속 완수 스트릭(🔥)이 상단과 각 카드에 표시된다.
8. 마지막 쪽까지 채우면 축하 화면이 뜨고, 같은 사이트의 **문제집 책장(day07)** 에 자동으로 꽂힌다.
9. 📤에서 오늘의 분량 카드를 9:16 이미지로 저장한다.

## 실행

`index.html`을 브라우저에서 그대로 열면 된다. 빌드 없음, 의존성 없음.

## 계산 방식

- `하루 분량` 방식은 하루 쪽수를 고정하고 완주 예정일을 다시 계산한다.
- `기한` 방식은 매일 **남은 쪽수 ÷ 남은 날수**로 하루 분량을 다시 나눈다. 밀리면 하루 분량이 자동으로 늘어난다.
- 밀린 정도는 `처음 계획대로라면 어제까지 끝냈어야 할 쪽 − 실제로 푼 쪽`으로 계산한다.
- 연속 완수는 그날 푼 쪽수가 하루 분량 이상인 날을 오늘(또는 어제)부터 거슬러 센다.

## day07 책장 연동

같은 GitHub Pages 도메인이라 `localStorage`를 공유한다. 완주하면 day07의 저장소 키 **`workbook-shelf-v1`** 에 day07과 같은 형식으로 책을 추가한다.

- 과목·대상 학년은 day07과 같은 제목 분석 규칙으로 채운다.
- 메모에는 `하루 15쪽씩 20일 완주 (300쪽)`이 자동으로 들어간다.
- day07을 아직 한 번도 안 썼으면 프로필(닉네임·학년)도 같이 만들어 준다.
- 같은 제목·같은 시작일이면 중복으로 꽂지 않는다.

## 책 검색에 대해

- 기본은 **Google Books API**(day01 독서 달력과 같은 키). 이 키는 `bominkimkr.github.io` 리퍼러 제한이 있어 **배포된 주소에서만 검색된다.** 로컬 파일로 열면 안내와 함께 직접 입력으로 넘어간다.
- **총 페이지수**는 Google Books에 `pageCount`가 있을 때만 자동으로 채워진다. 없으면 직접 입력한다(카카오 책 검색은 페이지수를 주지 않는다).
- ⚙️ 설정에 카카오 REST 키를 넣으면 제목 검색은 카카오를 우선 쓴다. 이 키는 day07과 공유한다.
