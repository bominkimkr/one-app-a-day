# Day 01 — 독서 달력

책 제목만 입력하면 표지, 저자, 출판사, 페이지수를 Google Books API로 자동으로 채워주는 독서 기록 달력.

- 책 제목 검색 → 후보 선택 (검색에 없으면 직접 입력)
- 책의 분류를 감성적인 라벨로 자동 분류하고, 어울리는 소개 문장을 자동 생성
- 달력의 하루하루에 그날 읽은 책 표지와 마음에 남은 문장을 기록
- "다 읽었어요" 버튼으로 완독 처리 + 느낀점/배운점 기록, 완독한 책은 "내 책장"에서 모아보기
- 한 달을 매일 빠짐없이 채우면 축하 애니메이션과 함께 뱃지 획득, 1년 12개 뱃지를 모으면 그 해의 독서 성향 한 줄 요약 제공
- 데이터는 모두 `localStorage`에 저장, 빌드 없이 `index.html` 하나로 동작

Open `index.html` directly in a browser to run it. Google Books 검색은 인터넷 연결이 필요하며, 검색이 안 되는 책은 직접 입력할 수 있습니다.
