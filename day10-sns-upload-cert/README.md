# SNS 업로드 인증

인스타그램 업로드 캡처를 날짜별 썸네일로 모으는 월간·연간 캘린더.

- 캡처 업로드 → 날짜 칸에 썸네일, 릴스/캐러셀 구분
- 월간 보기: 거북이 진행 그래프, 계획(점선 칸), 연속 업로드, 팔로워 그래프
- 연간 보기: 12달 한눈에, 베스트 달
- 주간 계획 붙여넣기, AI 자동 주제 입력

## 실행 환경
현재 버전은 claude.ai Artifact 런타임(`window.claude.use('db' | 'assets' | 'sample')`)으로 저장·이미지·AI 기능을 씁니다.
이 파일만 단독으로 열면 화면은 보이지만 기록 저장은 되지 않습니다.
누구나 쓰는 사이트로 배포하려면 저장소를 Supabase(DB·Storage·Auth)로 교체해야 합니다.
