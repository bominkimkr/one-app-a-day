# Day 03 — 인스타그램 30일 챌린지

여러 참가자가 함께 쓰는 30일 인증 챌린지. 매일 인스타그램 릴스나 게시글 링크를 남기면 자동으로 릴스/게시글을 구분하고, 공개 게시물은 인스타그램 공식 임베드로 실제 게시물이 보입니다.

- 이름 + 인스타 아이디 + 4자리 비밀번호로 참가 등록 (스토리 링크는 등록 불가)
- 함께 보기: 전체 참가자의 진행률(30일 중 며칠), 🔥 연속 기록, 오늘 인증 여부
- 참가자를 누르면 그 사람의 30일 달력과 인스타그램 게시물들을 볼 수 있음
- 30일을 다 채우면 완주 배너 + 릴스/게시글 개수 + 최장 연속 기록 요약
- "공유 카드" 버튼으로 "N일차 달성!" 이미지를 만들어 저장 가능
- 부적절한 참가자/게시물은 운영자 비밀번호로 숨길 수 있음

데이터는 Supabase(프로젝트 `insta-challenge`, `insta_` 테이블)에 저장됩니다. 비밀번호는 해시로만 저장되고, anon(publishable) 키만 사용하며 쓰기 작업은 전부 PIN을 검증하는 SECURITY DEFINER 함수를 통해서만 이루어집니다. 스키마는 `../sql/insta_challenge_schema.sql`에 있습니다.

Open `index.html` directly in a browser to run it.
